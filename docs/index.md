# Meta Content

Add custom content or scripts per post/page.

```mermaid
graph LR
    A[📝 Post/Page] --> B[🔌 Meta Box]
    B --> C[📄 Custom Content]
    
    style A fill:#F97316,stroke:#7C90A0,color:#fff
    style B fill:#6366F1,stroke:#7C90A0,color:#fff
    style C fill:#10B981,stroke:#7C90A0,color:#fff
```

## Quick Start

1. **Install** → Upload plugin
2. **Edit** → Add content in Meta Box
3. **Display** → Use `[metacontent]` shortcode

## Features

| Feature | Description |
|---------|-------------|
| 📝 Meta Box | Per-post content |
| 📜 Scripts | Add custom scripts |
| 🔗 Shortcode | `[metacontent]` |
